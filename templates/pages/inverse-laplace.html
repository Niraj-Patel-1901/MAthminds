Inverse Laplace Transform

Partial fractions, convolution theorem, and complex inversion

Definition

  • \[f(t) = \frac{1}{2\pi i}\int_{c-i\infty}^{c+i\infty} F(s)e^{st}ds\]
  • Bromwich integral where c > all singularities

Common Transforms

  • \[\mathcal{L}^{-1}\{\frac{1}{s}\} = 1\]
  • \[\mathcal{L}^{-1}\{\frac{1}{s-a}\} = e^{at}\]
  • \[\mathcal{L}^{-1}\{\frac{1}{s^2+a^2}\} = \frac{1}{a}\sin(at)\]
  • \[\mathcal{L}^{-1}\{\frac{s}{s^2+a^2}\} = \cos(at)\]

Properties

  • Linearity: \[\mathcal{L}^{-1}\{aF(s) + bG(s)\} = af(t) + bg(t)\]
  • Shifting: \[\mathcal{L}^{-1}\{e^{-as}F(s)\} = f(t-a)u(t-a)\]
  • Scaling: \[\mathcal{L}^{-1}\{F(as)\} = \frac{1}{a}f(\frac{t}{a})\]

Convolution

  • \[\mathcal{L}^{-1}\{F(s)G(s)\} = \int_0^t f(t-\tau)g(\tau)d\tau\]
  • \[f(t)*g(t) = \int_0^t f(t-\tau)g(\tau)d\tau\]
