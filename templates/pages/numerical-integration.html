Euler • Modified Euler • RK4 • Trapezoidal • Simpson’s 1/3 • Simpson’s 3/8

Euler: \\( y_{n+1} = y_n + h f(x_n, y_n) \\)
Modified Euler (Heun): \\( k_1 = f(x_n, y_n), \\; k_2 = f(x_n + h, y_n + hk_1) \\), \\( y_{n+1} = y_n + \\frac{h}{2}(k_1 + k_2) \\)
RK4: \\( y_{n+1} = y_n + \\frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \\)
Trapezoidal: \\( \\int_a^b f(x)dx \\approx \\frac{h}{2}[f_0 + 2\\sum f_i + f_n] \\)
Simpson 1/3: \\( \\int_a^b f(x)dx \\approx \\frac{h}{3}[f_0 + 4f_1 + 2f_2 + \\dots + f_n] \\)
Simpson 3/8: \\( \\int_a^b f(x)dx \\approx \\frac{3h}{8}[f_0 + 3f_1 + 3f_2 + 2f_3 + \\dots + f_n] \\)
