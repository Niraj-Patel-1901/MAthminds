Matrices

Echelon form, rank, determinants, and PAQ factorization

Matrix Operations

  • Addition: \[A + B = [a_{ij} + b_{ij}]\]
  • Scalar multiplication: \[kA = [ka_{ij}]\]
  • Matrix multiplication: \[(AB)_{ij} = \sum_{k=1}^n a_{ik}b_{kj}\]

Determinants

  • 2×2 matrix: \[\det(A) = ad - bc\]
  • Properties: \[\det(AB) = \det(A)\det(B)\]
  • Inverse: \[A^{-1} = \frac{1}{\det(A)}\text{adj}(A)\]

Row Operations

  • Swap rows
  • Multiply row by non-zero scalar
  • Add multiple of one row to another

PAQ Factorization

  • P: Row permutation matrix
  • Q: Column permutation matrix
  • A = PAQ where A is in echelon form
