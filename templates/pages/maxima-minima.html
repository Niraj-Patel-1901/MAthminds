Maxima & Minima

Optimization, critical points, and Lagrange multipliers

Critical Points

  • First derivatives: \[\frac{\partial f}{\partial x} = 0, \frac{\partial f}{\partial y} = 0\]
  • Second derivatives: \[f_{xx} = \frac{\partial^2 f}{\partial x^2}, f_{xy} = \frac{\partial^2 f}{\partial x\partial y}, f_{yy} = \frac{\partial^2 f}{\partial y^2}\]
  • Discriminant: \[D = f_{xx}f_{yy} - (f_{xy})^2\]

Second Derivative Test

  • If \(D > 0\) and \(f_{xx} > 0\): Local minimum
  • If \(D > 0\) and \(f_{xx} < 0\): Local maximum
  • If \(D < 0\): Saddle point
  • If \(D = 0\): Inconclusive

Lagrange Multipliers

  • Lagrangian: \[L(x,y,\lambda) = f(x,y) - \lambda g(x,y)\]
  • Conditions: \[\frac{\partial L}{\partial x} = 0, \frac{\partial L}{\partial y} = 0, \frac{\partial L}{\partial \lambda} = 0\]
  • Constraint: \[g(x,y) = c\]
